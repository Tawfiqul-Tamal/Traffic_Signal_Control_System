# 🚦 Traffic Signal Control System Using 555 Timer IC

## Project Overview

This project demonstrates a hardware-based **Traffic Signal Control System** using the popular **555 Timer IC**. The circuit sequentially controls **Red, Yellow, and Green LEDs**, simulating the operation of a real-world traffic signal.

The system is designed to showcase how timer-based electronic circuits can automate traffic light sequences, helping to improve traffic flow and reduce congestion. It also serves as an excellent educational project for understanding timing circuits, LED control, and practical applications of electronic components.

## Working Principle

1. The **555 Timer IC** generates timing pulses based on the connected resistor-capacitor (RC) network.
2. These timing signals control the operation of the LEDs in a predefined sequence.
3. The **Green LED** turns ON first, indicating traffic movement.
4. The **Yellow LED** activates after a short delay, signaling caution.
5. Finally, the **Red LED** turns ON to indicate a stop condition.
6. The cycle continuously repeats, mimicking the functionality of an actual traffic signal system.
